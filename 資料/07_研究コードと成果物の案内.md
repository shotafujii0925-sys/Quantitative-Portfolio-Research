# 研究コードと成果物の案内

VS Codeではこのプロジェクトを開き、専用`.venv/Scripts/python.exe`を選ぶ。
Notebookのコードセルは非表示にせず、関数名のF12または実装リンクで共通処理へ移動する。
各Notebookは目的・理論・データ・条件・実装・結果・統計解釈・運用解釈・限界の順。
変更前の原本は`outputs/reports/編集前ノート/`に保持した。

## 今回の計算の読み順

1. [追加設計](06_リスク統一比較の設計.md)：後付け研究、時点、資金調達、上限の定義。
2. [volatility_target.py](../src/quant_ai/volatility_target.py)：過去共分散→予測σ→エクスポージャー。
3. [leveraged_backtest.py](../src/quant_ai/leveraged_backtest.py)：旧保有→利息→約定→コスト→新保有。
4. [downside_metrics.py](../src/quant_ai/downside_metrics.py)：Sortino・ES・Calmar・回復の定義。
5. [risk_research.py](../src/quant_ai/risk_research.py)：全条件、旧結果照合、ペアブロック区間。
6. [research_plots.py](../src/quant_ai/research_plots.py)と[research_report.py](../src/quant_ai/research_report.py)：図と日本語報告。

- 条件付き再標本化（ローカル生成：`outputs/reports/リスク統一比較/conditional_bootstrap.csv`）

## 実行

```powershell
.\.venv\Scripts\python.exe scripts/run_risk_normalized_study.py
.\.venv\Scripts\python.exe scripts/execute_notebooks.py
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\ruff.exe check src tests scripts
.\.venv\Scripts\ruff.exe format --check src tests scripts
```

図と報告だけ作り直す場合は`run_risk_normalized_study.py --render-only`。
研究判断やモデル選択を行ったら、未見期間による別の検証が必要。
