# VIXボラ目標の研究計画

新しい検証結果を見る前に記録した計画です。ただし、分析者は同じ期間のボラ目標の既存結果と、S&P500でのVIX研究の結果をすでに知っています。そのため独立した未見データの検証ではなく、事後研究として扱います。

## 問い

**株式ボラの予測をVIXに置き換えると、過去の実現ボラだけを使う場合より、ボラ目標の成績は改善するか。**

期待収益は推定しません。VIXはリスクの予測だけに使います。

## 共通条件

既存の主条件に揃えます。

- SPY、TLT、GLD（USD、調整終値）
- 評価は2006-01-03〜2026-10-29
- 月次判断、翌営業日終値で約定、新保有の損益はその次の終値から
- 片道5bps、目標ボラ年率10%、月次目標倍率の上限1.5倍、預金・借入金利0%
- 基本配分と相関は過去252日で推定

VIXは判断日の終値を使います。VIXの確定は指数より遅いものの、約定は翌営業日終値なので先読みにはなりません。

## 基本配分

1. SPYのみ
2. 等ウェイト
3. 最小分散

## 比較するボラ予測

いずれもSPYのボラだけを置き換え、TLT・GLDのボラと資産間の相関は過去252日の値を使います。

| 名前 | SPYのボラの予測 |
|---|---|
| none | ボラ目標なし（倍率1倍） |
| hist252 | 過去252日の標準偏差（既存研究の主条件） |
| rv21 | 過去21日の標準偏差 |
| vix_cal | VIX × exp(k)。kは判断日までに結果が確定した日の log(実現ボラ / VIX) の平均 |
| vix_raw | VIXをそのまま使用（校正なし） |

`vix_cal` の実現ボラは、約定後の保有期間に合わせて i+2〜i+22 日のリターンから計算し、i+22 日が判断日以前の分だけを使います。傾きは1に固定し、推定するのは水準 k だけです。

追加で、最小分散のウェイト自体を `vix_cal` の共分散で決める `min_variance + vix_cal（配分も変更）` を比較します。

## 評価

**主要な比較（事前に固定）:** `vix_cal − rv21` のSharpe差を、3つの基本配分について比べます。63日ペア循環ブロック・ブートストラップ10,000回の両側pにHolm補正をかけます。

**VIXに価値があると判定する条件（すべて満たす場合）:**

1. 少なくとも1つの基本配分でHolm補正後のp < 0.05で、Sharpe差が正
2. その基本配分で、ボラ10%に換算したCAGRの差も正
3. その基本配分で、最大DDの差のCIが悪化側だけに偏らない

**副次的な比較:**

- `vix_cal − hist252`、`vix_cal − none`、`rv21 − hist252`、`hist252 − none`（補正なしの参考値）
- ブロック長21日、126日の感度
- SPYの次の21日実現ボラに対する予測精度（QLIKE、log誤差、バイアス）
- VIXを循環シフトしたプラセボとのSharpe比較（21日刻み、最小シフト252日）
- ショック前の倍率: 高値の直前の判断日における倍率
- 下落局面と、その後1年の反発局面の成績

**指標:** CAGR、実現ボラ、Sharpe（rf=0）、最大DD、平均倍率、年率回転率。ボラ10%に換算したCAGRは事後のスケーリングによる記述的な値で、取引可能な戦略ではありません。

**局面（判断日の情報では使わず、結果の分類だけに使います）:**

| 局面 | 期間 |
|---|---|
| 金融危機の下落 | 2007-10-09〜2009-03-09 |
| 金融危機後の反発 | 2009-03-10〜2010-03-09 |
| コロナの下落 | 2020-02-19〜2020-03-23 |
| コロナ後の反発 | 2020-03-24〜2021-03-23 |
| 2022年の株債同時下落 | 2022-01-03〜2022-10-12 |

## 感度分析（報告のみで、ここから設定を選びません）

`hist252`、`rv21`、`vix_cal` と3つの基本配分について、次を変えて報告します。

- 目標ボラ 8%、12%
- 倍率上限なし、上限1倍（借入なし）
- 預金/借入金利 2%/3%、4%/6%
- 片道コスト 20bps
- 週次判断（基本配分は直近の月末の値を維持）

## 想定される限界

- 既存の結果を知ったうえでの事後研究で、独立した検証ではありません
- VIXの傾きを1に固定した根拠は、同じ期間と重なる別研究の結果です
- 初期の校正は約1年分のデータしかなく、不安定な可能性があります
- ブートストラップは得られた収益系列に条件付きで、配分の再推定を含みません
- 調整済み価格は再取得で変わる可能性があり、既存の公表値と完全には一致しないかもしれません

## 計画後の追加（最初の結果を見た後に追加）

最初の結果を見た後、利用者の関心である「SharpeとCAGRの両立」を確かめるために、次の2点を追加しました。主要な比較と判定条件は変えていません。

- `min_variance__rv21`、`min_variance__vix_cal`、配分も変更する版の、SPY買い持ちとの差（参考値）
- 配分も変更する版の、金利2%/3%、4%/6%と倍率上限1倍の感度
